
# Learning Outcomes

Through this mini project, I gained an understanding of important web application security concepts.

## 1. SQL Injection
- Understood how insecure database queries can expose applications to attacks.
- Learned about different types of SQL Injection.
- Understood the importance of parameterized queries.

## 2. Cross-Site Scripting
- Learned the differences between Reflected, Stored, and DOM-Based XSS.
- Understood how unsafe input and output handling can affect users.
- Learned about output encoding and Content Security Policy.

## 3. Practical Security Skills
- Understood the purpose of a controlled web security testing environment.
- Learned how to observe and document application behavior.
- Recognized the importance of collecting evidence before confirming vulnerabilities.

## 4. Overall Conclusion
This project improved my understanding of common web application vulnerabilities and introduced me to practical security assessment concepts. It also highlighted the importance of secure coding and responsible testing.
