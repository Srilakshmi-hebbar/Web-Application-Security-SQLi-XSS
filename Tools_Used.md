
# Tools Used

## 1. Kali Linux
A Linux distribution used for cybersecurity learning and security testing.

## 2. bWAPP
A deliberately vulnerable web application designed for practicing web security concepts.

## 3. Docker
Used to deploy and manage the vulnerable application in a local environment.

## 4. Burp Suite
A web security testing platform used to inspect HTTP requests and responses.

## 5. Web Browser
Used to access the application and observe its behavior during testing.

## 6. Gobuster
A directory and file discovery tool used for web reconnaissance.

## Note
This list describes tools relevant to the project. Only tools actually used during the practical assessment should be reported as used.
