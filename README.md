
# Web Application Security – SQL Injection and XSS

## Project Overview
This mini project focuses on understanding common web application vulnerabilities, particularly SQL Injection (SQLi) and Cross-Site Scripting (XSS).

The practical work is intended to help understand how insecure input handling can affect web applications and how these vulnerabilities can be prevented.

## Objectives
- Understand SQL Injection vulnerabilities.
- Understand Reflected and Stored Cross-Site Scripting.
- Explore how applications process user input.
- Observe application responses during authorized security testing.
- Learn security practices to prevent SQLi and XSS.

## Tools and Environment
- Kali Linux
- bWAPP
- Docker
- Web Browser
- Burp Suite (where applicable)

## Methodology
1. Set up the vulnerable application in a controlled local environment.
2. Access the application's security testing features.
3. Explore SQL Injection testing.
4. Study Cross-Site Scripting testing.
5. Observe and document application responses.
6. Review suitable prevention techniques.

## Learning Outcomes
- Developed an understanding of SQL Injection.
- Learned the basic concepts of Cross-Site Scripting.
- Understood the importance of secure input handling and output encoding.
- Learned how security testing helps identify web application weaknesses.

## Security Note
All practical testing should be conducted only in an authorized, controlled lab environment.
